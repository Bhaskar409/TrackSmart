# 🚀 TrackSmart – Employee Management Dashboard  

**TrackSmart** is a web-based Employee Management System that provides a centralized platform for managing employees, projects, and organizational activities.  
Each employee gets a **personalized dashboard** with tools to streamline daily tasks and improve productivity.  

---

## ✨ Features  
- 🔐 **Secure Login** – Employees can log in using email or employee ID  
- 📂 **Project Management** – View assigned projects and track progress  
- 📅 **Interactive Calendar** – Manage schedules and deadlines  
- 📝 **Leave Requests** – Apply and track leave applications  
- 📊 **Attendance Tracking** – Monitor employee attendance records  
- 🔔 **Notifications** – Get updates about projects, tasks, and events  
- ⚙️ **Admin Tools** – DBA/Admin manages database and content distribution  

---

## 🛠 Tech Stack  
- **Frontend:** HTML, CSS, JavaScript (responsive and interactive design)  
- **Backend:** Node.js, Express.js  
- **Database:** MySQL

## ⚡ Getting Started  

**1️⃣ Clone the Repository**
git clone https://github.com/your-username/TrackSmart.git
cd TrackSmart

**2️⃣Install Dependencies**
cd backend<br/>
npm install

**3️⃣Setup Database**

**Install MySQL and create a database**<br/>
**Import the provided .sql script from the database/ folder**

**4️⃣Run the Server**
